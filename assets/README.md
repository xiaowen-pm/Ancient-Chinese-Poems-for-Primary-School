# 资源库 · 小学生必背古诗词

本目录收录两套原始素材，供「必背诗笺」整理、校对和再发布使用：

| 素材来源 | 内容 |
| --- | --- |
| `75首诗词图文版` | 75 首古诗的图片版、PDF 版、跟读视频 |
| `小学生必背古诗词75-80首-10个版本` | 同一批古诗的 10 套朗读音频（含 75+80 首版本） |

仓库里只提交轻量文件（图片、PDF、文档，约 58 MB）。音频、视频和一个 257 MB 的 Word 合集因为超出 GitHub 单文件 100 MB 的限制，放在 [Releases](https://github.com/xiaowen-pm/Ancient-Chinese-Poems-for-Primary-School/releases) 里下载。


- 图片版和 PDF 版都带拼音和译文，可直接打印成读本；PDF 为扫描件，没有文字层，需要检索请用图片版或自行 OCR。
